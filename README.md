# EVENTFLOW

Русскоязычное SPA оформления билетов на вымышленный фестиваль «Ночь большого звука»: выбор, участники, проверка заказа, результат.

## Запуск

Node.js 22.12+ и npm:

```sh
npm ci
npm run dev
```

Откройте адрес Vite (обычно http://127.0.0.1:5173). В PowerShell при запрете npm.ps1 используйте `npm.cmd`.

## Правила и демонстрация

В заказе 1–4 участника, имя и возраст каждого, один email. До 14 лет билет стоит 1 000 ₽, с 14 — 2 000 ₽. Всем младше 18 нужен участник 18+ в том же заказе; 14–17 лет покупают полный билет. Сервисного сбора нет.

Имя: 2–80 символов, русские буквы с Ё/ё или латиница с диакритикой; между частями допустимы пробел, дефис и апостроф. Пробелы нормализуются после выхода из поля. Проверяется формат, не существование имени. Возраст: десятичные цифры 0–120; `1e2`, `0x12`, `+18` и дроби отклоняются, начальные нули допустимы. Несовместимый тариф исправляется вручную.

1. Выберите полный и детский билеты, введите вымышленные имена, 18 и 10 лет, `demo@example.com`. На проверке итог — 3 000 ₽; «Изменить» возвращает заполненные поля.
2. Выберите «Успешное оформление» и подтвердите. После асинхронной проверки появится номер демо-заказа.
3. Для второго результата выберите «Мест нет» перед подтверждением. Заказ не создаётся; возврат сохраняет данные. Затем можно изменить сценарий и повторить.

Mock API работает локально с задержкой и выбранным результатом. Оплаты, писем и настоящих билетов нет. Во время запроса повторная отправка блокируется. Черновик хранится в памяти вкладки до перезагрузки; внешним сервисам данные не передаются.

## Стек и проверки

React 19, TypeScript strict, Vite, Tailwind CSS, Lucide React; useReducer управляет оформлением. `src/domain/` — цены и валидация; `src/services/` — mock gateway; `src/components/` и `src/features/booking/` — интерфейс. Графика локальная в `assets/`.

```sh
npm run typecheck
npm run lint
npm run test:golden
npm run build
npm run preview
npx playwright install chromium
npm run test:browser
```

Vitest/React Testing Library проверяют бизнес-правила и React-сценарии. Playwright проверяет оформление, ошибки, sold-out, клавиатуру, 360/390/768/1440 px, zoom 200% и production assets. Он запускает и останавливает preview на порту 4173. Можно использовать установленный Chromium через `EVENTFLOW_CHROMIUM_PATH`. Каталог результатов вне проекта задаётся `EVENTFLOW_EVIDENCE_DIR` и создаётся автоматически. Zoom использует отдельный временный профиль. Проверка на физических устройствах и в других браузерах выполняется отдельно.
