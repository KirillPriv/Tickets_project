# EVENTFLOW

EVENTFLOW — русскоязычное веб-приложение для оформления билетов на вымышленный фестиваль «Ночь большого звука». Полный пользовательский путь от выбора билетов до результата заказа объединяет адаптивный интерфейс, проверку бизнес-правил и асинхронное подтверждение через локальный mock API.

## Возможности

- **Четыре этапа покупки:** выбор билетов → данные участников → проверка заказа → результат.
- **Расчёт стоимости:** тариф по возрасту, состав заказа и итог в рублях, редактирование перед подтверждением.
- **Валидация:** имена, возраст, контактный email, соответствие тарифа и наличие взрослого сопровождающего.
- **Два результата:** успешное оформление с номером демо-заказа или отсутствие мест; защита от повторной отправки и сохранение ввода при ошибках и переходах.
- **Адаптивность и доступность:** поддержка экранов от 360 px, работа с клавиатурой, управление фокусом и понятные ошибки у полей.

## Технологический стек

- **Интерфейс:** React 19, TypeScript в строгом режиме, Tailwind CSS, Lucide React.
- **Сборка и качество кода:** Vite, ESLint.
- **Тестирование:** Vitest, React Testing Library, Playwright.

## Архитектура

| Каталог | Назначение |
| --- | --- |
| [`src/domain/`](src/domain/) | Типы, чистые функции расчёта цены и валидации, редьюсер оформления. |
| [`src/features/booking/`](src/features/booking/) | Четыре экрана покупки и координация переходов и подтверждения заказа. |
| [`src/components/`](src/components/) | Общие элементы интерфейса: счётчики билетов, карточки участников, индикатор этапов и сводка заказа. |
| [`src/services/`](src/services/) | Типизированный контракт `BookingGateway` и локальная имитация API с задержкой и выбранным результатом. |

`useReducer` в `BookingFlow` управляет черновиком заказа, текущим этапом, демонстрационным сценарием и статусом подтверждения. Правила расчёта и валидации вынесены из интерфейса в `domain`. Графика хранится локально в [`assets/`](assets/).

## Запуск

Node.js 22.12+ и npm:

```sh
npm ci
npm run dev
```

Откройте адрес Vite (обычно [http://127.0.0.1:5173](http://127.0.0.1:5173)). В PowerShell при запрете `npm.ps1` используйте `npm.cmd`.

## Правила покупки

В заказе 1–4 участника, имя и возраст каждого, один email. До 14 лет билет стоит 1 000 ₽, с 14 — 2 000 ₽. Всем младше 18 нужен участник 18+ в том же заказе; 14–17 лет покупают полный билет. Сервисного сбора нет.

Имя: 2–80 символов, русские буквы с Ё/ё или латиница с диакритикой; между частями допустимы пробел, дефис и апостроф. Пробелы нормализуются после выхода из поля. Проверяется формат, не существование имени. Возраст: десятичные цифры 0–120; `1e2`, `0x12`, `+18` и дроби отклоняются, начальные нули допустимы. Несовместимый тариф исправляется вручную.

## Демонстрационный сценарий

Используйте вымышленные данные.

### Успешная покупка

1. Выберите один полный и один детский билет, нажмите «Продолжить».
2. Введите имена «Анна» и «Иван», возраст 18 и 10 лет соответственно, контактный email `demo@example.com`.
3. Перейдите к проверке заказа: итог — **3 000 ₽**. Кнопка «Изменить» возвращает к заполненным полям.
4. В блоке «Демонстрационный сценарий» выберите «Успешное оформление» и нажмите «Подтвердить заказ». После асинхронной проверки появится номер демо-заказа.

### Отсутствие мест

1. Нажмите «Оформить ещё один заказ» и повторите выбор билетов и ввод данных.
2. На шаге проверки выберите «Мест нет» и нажмите «Подтвердить заказ».
3. После проверки появится экран **«Мест больше нет»**. Заказ не создаётся. Нажмите «Вернуться к участникам»: данные сохранены. Можно вернуться к проверке, изменить сценарий и повторить подтверждение.

Mock API работает локально с задержкой и выбранным результатом. Оплаты, писем и настоящих билетов нет. Во время запроса повторная отправка блокируется. Черновик хранится в памяти вкладки до перезагрузки; внешним сервисам данные не передаются.

## Проверки и сборка

```sh
npm run typecheck
npm run lint
npm run test:golden
npm run build
```

Для просмотра собранного приложения:

```sh
npm run preview
```

Для браузерных тестов сначала выполните `npm run build`, затем установите Chromium и запустите Playwright:

```sh
npx playwright install chromium
npm run test:browser
```

| Инструменты | Что проверяется |
| --- | --- |
| Vitest и React Testing Library | Бизнес-правила, границы возрастных тарифов, валидация, переходы между этапами, сохранение данных и защита от двойной отправки. |
| Playwright | Покупка и отсутствие мест в Chromium, ошибки форм, клавиатура, ширины 360/390/768/1440 px, масштаб 200% и загрузка графики из сборки. |

Playwright самостоятельно запускает и останавливает сервер предпросмотра на порту 4173 — перед тестами он должен быть свободен. Можно использовать установленный Chromium через `EVENTFLOW_CHROMIUM_PATH`. Каталог результатов вне проекта задаётся `EVENTFLOW_EVIDENCE_DIR` и создаётся автоматически. Проверка на физических устройствах и в других браузерах выполняется отдельно.
