# EVENTFLOW — стартовый комплект для SQOCH

**Статус:** подготовка к разработке (это документация и готовые графические ассеты, ещё не готовое React-приложение).

EVENTFLOW — небольшое **русскоязычное** SPA для покупки билетов на одно демонстрационное мероприятие. Цель — качественно закрыть **тестовое задание SQOCH**, показать UX, инженерное мышление, защиту от ошибок и аккуратную архитектуру; не строить преждевременно коммерческую платформу.

## С чего начать Codex

1. Прочитать **`AGENTS.md`** (обязательные правила, действует во всех последующих сессиях).
2. Прочитать **`PROJECT_BRIEF.md`** (единый источник требований и архитектуры).
3. Прочитать **`docs/SPRINTS.md`**, **`docs/GOLDEN_TESTS.md`**, **`docs/ASSET_GUIDE.md`**.
4. Выполнить **`docs/CODEX_SPRINT_PROMPTS.md` → S01** одним крупным спринтом. Дальше только после evidence, golden-gate и фиксации результата.
5. Использовать готовые изображения из `assets/`; `design-reference/` — визуальное вдохновение, а **не макет для посимвольного копирования**.

## Структура комплекта

```text
EVENTFLOW_Starter_Kit/      ← можно использовать как будущий корень Git-репозитория
├── README.md
├── AGENTS.md                 ← правила для Codex
├── PROJECT_BRIEF.md         ← продукт, архитектура, приемка
├── docs/
│   ├── SPRINTS.md
│   ├── GOLDEN_TESTS.md
│   ├── ASSET_GUIDE.md
│   └── CODEX_SPRINT_PROMPTS.md
├── assets/
│   ├── images/               ← готовые WebP и текстура
│   └── brand/                ← готовые SVG
├── design-reference/        ← референс, НЕ использовать как экранный растр
├── reference/               ← оба оригинальных PDF SQOCH
└── scripts/
    ├── verify.ps1           ← обязательные проверки после S01
    └── checkpoint.ps1       ← проверка и исходный review ZIP вне Git
```

**После S01** Codex создаёт `src/`, `index.html`, `package.json`, настройки Vite/TypeScript/Tailwind/Vitest. Он не должен удалять исходные требования или переименовывать документы.

## Предполагаемые команды после S01

```powershell
npm install
npm run dev
npm run typecheck
npm run lint
npm run test:golden
npm run build
```

`npm run test:golden` должен запускать короткий стабильный набор критических тестов. Эти команды **создаёт и проверяет Codex в S01**, их наличие в стартовом комплекте пока не означает готовности приложения.

## Архивы и контрольные точки

На Windows рекомендуемая структура:

```text
EVENTFLOW_project/
├── eventflow/           ← Git-репозиторий (содержимое этого комплекта)
└── _artifacts/          ← вне Git, отдельное место для review ZIP и evidence
    ├── review/
    ├── evidence/
    └── rollback/
```

Не складывать ZIP, `node_modules`, сборки и бесконечные скриншоты в Git. Не переносить реальные персональные сведения пользователя в демонстрационные данные.

**Источники требований:** `reference/Sqoch — Тест 1.pdf` (основной источник); `reference/SQOCH_Информация для кандидатов.pdf` (контекст вакансии и процедуры сдачи). При расхождении приоритет у конкретных условий теста.
