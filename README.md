# EVENTFLOW

Русскоязычное приложение оформления билетов на вымышленный музыкальный фестиваль «Ночь большого звука». Четыре этапа: выбор билетов, данные участников, проверка заказа, результат асинхронного подтверждения.

## Запуск

Нужен Node.js 22.12 или новее. Зависимости зафиксированы в `package-lock.json`.

```sh
npm ci
npm run dev
```

Откройте адрес, напечатанный Vite (обычно `http://127.0.0.1:5173`). В Windows PowerShell с ограничением выполнения сценариев используйте `npm.cmd` вместо `npm`; менять политику PowerShell не требуется.

```sh
npm run typecheck
npm run lint
npm run test:golden
npm run build
npm run preview
```

Сборка создаётся в `dist/`. Внешние сервисы, ключи и серверная часть не нужны.

## Проверить сценарии

1. Добавьте полный и детский билеты. Укажите вымышленные имена, возраст 18 и 10 лет, email `demo@example.com`.
2. На проверке заказа итог составит **3 000 ₽**. Кнопка «Изменить» возвращает к заполненным полям.
3. Подтвердите заказ: во время проверки мест кнопка заблокирована. После ответа появится номер демо-заказа.
4. Для другого результата выберите на проверке сценарий **«Мест нет»**, затем подтвердите. Заказ не создастся; возврат к участникам сохранит все данные. Переключатель сам по себе не создаёт результат.
5. При правке возраста с 10 на 14 стоимость сразу изменится на 2 000 ₽. Выберите полный тариф вручную: несовместимый тариф блокирует переход, автоматически он не меняется.

Это демонстрация: оплаты, отправки писем, QR, PDF и настоящих билетов нет. Используйте вымышленные данные. Черновик хранится в памяти вкладки и сбрасывается при перезагрузке. Изменение количества временно убирает участников, но повторное добавление того же тарифа восстанавливает их данные в текущей сессии.

## Правила

В одном заказе 1–4 участника. До 14 лет билет стоит 1 000 ₽, с 14 лет — 2 000 ₽. Возраст вводится только десятичными цифрами от 0 до 120: записи `1e2`, `0x12`, `+18` и дроби отклоняются. Начальные нули допустимы (`018` = 18 лет). Контактный email — один на весь заказ. Сервисного сбора нет.

Имя — 2–80 символов после нормализации, русские буквы (включая Ё/ё) или латиница (включая буквы с диакритикой). Части имени можно разделять пробелом, дефисом, прямым или типографским апострофом: `Анна-Мария`, `O'Connor`, `D’Arcy`. Цифры, эмодзи, посторонняя пунктуация и повторные разделители отклоняются. Внешние и повторные пробелы нормализуются после выхода из поля и перед подтверждением; во время набора текст не фильтруется. Проверка выполняется также в mock API.

Принятое толкование условия сопровождения: **всем младше 18 лет** нужен хотя бы один участник 18+ в том же заказе. Участники 14–17 лет покупают полный билет, но не могут сопровождать несовершеннолетнего. Это правило изолировано в доменной валидации.

## Устройство приложения

- React 19 + TypeScript strict + Vite; Tailwind CSS и CSS variables; иконки Lucide React.
- `src/domain/` — чистые функции цены и валидации; reducer управляет шагами, стабильными ID, черновиком и результатами.
- `src/features/booking/` — четыре экрана; `src/components/` — поля, счётчики, прогресс и итог заказа.
- `src/services/` — типизированный `BookingGateway` и детерминированный mock с задержкой. Результат появляется после ответа; guard и блокировка UI защищают от повторной отправки.
- `src/data/` — вымышленное событие; `assets/` — локальные обложки и брендовая графика. Видимый текст и все действия реализованы в HTML.
- `src/tests/` — Vitest + React Testing Library: возрастные границы, сопровождение, количество, цены, поля и сквозные сценарии, включая ошибки и повторные клики.
- `e2e/` — Playwright: настоящее оформление, sold-out, редактирование, новые ошибки полей и отсутствие горизонтальной прокрутки на 360/390/768/1440 px; нативный zoom Chromium 200% проверяется в отдельном временном профиле.

Форма управляется reducer: валидация едина для UI и mock API, отдельные библиотеки форм не понадобились. Персональные данные не сохраняются в `localStorage` и не отправляются в сеть. Номер демо-заказа — локальный последовательный номер, он не является глобально уникальным.

## Браузерные проверки

```sh
npx playwright install chromium
npm run build
npm run test:browser
```

Playwright автоматически запускает и останавливает preview на порту 4173. При необходимости путь к уже установленному Chromium задаётся переменной `EVENTFLOW_CHROMIUM_PATH`. Отчёт JSON и снимки сохраняются вне репозитория, по умолчанию в `../_artifacts/evidence/S02/`; другую папку можно задать через `EVENTFLOW_EVIDENCE_DIR`. Для zoom используется временный профиль: личный профиль браузера и настройки ОС не меняются.

Приложение поддерживает клавиатуру, подписи полей, локальные ошибки, перевод фокуса между этапами и уменьшенное движение по системной настройке. Проверки в Chromium не заменяют проверку во всех браузерах и на физических телефонах.

Точное время выполнения не фиксировалось. Видеозапись процесса и отдельное видео-демо в исходники не приложены.
